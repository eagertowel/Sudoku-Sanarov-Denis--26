# Sudokugame

Графическая игра **Судоку** на C#
---

## 1. Что реализовано в игре

В проекте есть:

- отдельное графическое окно приложения;
- главное меню;
- выбор уровня сложности;
- игровое поле 9x9;
- ввод чисел через кнопки;
- очистка выбранной клетки;
- подсказки;
- проверка поля;
- показ решения;
- таймер;
- ограничение количества ошибок;
- победа и поражение;
- разделение кода по папкам `Model`, `View`, `Controller`;
- обновление отображения через паттерн Observer.

---

## 2. Требования для запуска

Для запуска проекта нужен компьютер с Windows и установленная Visual Studio.

Рекомендуемый вариант:

- **Visual Studio 2022**;
- рабочая нагрузка **.NET desktop development** / **Разработка классических приложений .NET**;
- установленный **.NET SDK**.

Если проект настроен на:

```xml
<TargetFramework>net10.0-windows</TargetFramework>
```

нужно, чтобы на компьютере был установлен .NET 10 SDK.

Если у вас установлен .NET 8 SDK, можно заменить строку в файле `.csproj` на:

```xml
<TargetFramework>net8.0-windows</TargetFramework>
```

## 3. Как открыть проект

1. Распакуйте архив с проектом.
2. Желательно поместить проект в простую папку, например:

```text
C:\Sudokugame
```

3. Откройте Visual Studio.
4. Выберите:

```text
File → Open → Project/Solution
```

В русской версии:

```text
Файл → Открыть → Проект или решение
```

5. Откройте файл:

```text
Sudokugame.csproj
```

---

## 4. Как запустить игру через Visual Studio

После открытия проекта:

1. В правой панели **Solution Explorer / Обозреватель решений** найдите проект `Sudokugame`.
2. Нажмите по нему правой кнопкой мыши.
3. Выберите:

```text
Set as Startup Project
```

В русской версии:

```text
Назначить запускаемым проектом
```

4. Нажмите зелёную кнопку запуска сверху или клавишу:

```text
F5
```

Также можно запустить без отладки:

```text
Ctrl + F5
```

После запуска должно открыться отдельное окно игры.

## 5. Как запустить игру через терминал

Откройте терминал в папке проекта, где находится файл:

```text
Sudokugame.csproj
```

Затем выполните команды:

```bash
dotnet restore Sudokugame.csproj
dotnet build Sudokugame.csproj
dotnet run --project Sudokugame.csproj
```

Если проект находится в папке `C:\Sudokugame`, можно использовать:

```bat
cd /d C:\Sudokugame
dotnet restore Sudokugame.csproj
dotnet build Sudokugame.csproj
dotnet run --project Sudokugame.csproj
```

## 6. Как играть

После запуска откроется главное меню.

В главном меню можно выбрать уровень сложности:

- лёгкий;
- средний;
- сложный;
- эксперт.

После начала игры:

1. Нажмите мышкой на пустую клетку поля.
2. Нажмите кнопку с нужной цифрой.
3. Если нужно удалить число, выберите клетку и нажмите кнопку очистки.
4. Если нужна помощь, нажмите кнопку подсказки.
5. Чтобы проверить поле, нажмите кнопку проверки.
6. Чтобы увидеть готовое решение, нажмите кнопку показа решения.
7. Чтобы вернуться в меню, нажмите кнопку возврата в меню.

---

## 7. Правила судоку

Нужно заполнить поле 9x9 числами от 1 до 9.

Числа не должны повторяться:

- в одной строке;
- в одном столбце;
- в одном квадрате 3x3.

Игра считается выигранной, когда всё поле заполнено правильно.

Игра считается проигранной, если игрок превышает лимит ошибок.

## 8. Архитектура проекта

Проект разделён на три основные части:

```text
Model
View
Controller
```

### Model

Папка `Model` содержит игровую логику:

- хранение состояния поля;
- генерацию судоку;
- проверку ходов;
- проверку победы;
- обработку ошибок;
- выдачу подсказок;
- уведомление наблюдателей.

Модель не содержит кода Windows Forms и может быть перенесена в другой проект без переписывания логики игры.

### View

Папка `View` отвечает за отображение:

- главное меню;
- игровое поле;
- кнопки;
- окна правил;
- визуальное обновление состояния игры.

View получает данные от модели через Observer и обновляет интерфейс после изменения состояния модели.

### Controller

Папка `Controller` отвечает за передачу команд от интерфейса к модели.

Контроллер:

- принимает действие игрока;
- вызывает методы модели;
- не содержит логики отрисовки;
- не хранит игровое состояние.

---

## 9. Observer

Для обновления интерфейса используется паттерн **Observer**.

View подписывается на изменения модели.  
Когда состояние игры меняется, модель отправляет объект состояния `GameStateSnapshot` всем подписчикам.

Это позволяет не использовать постоянный игровой цикл и не заставлять View вручную проверять, изменились ли данные.

## 11. Возможные ошибки и исправления

### Ошибка NETSDK1004

Текст ошибки может быть таким:

```text
project.assets.json not found
```

или:

```text
файл ресурсов obj\project.assets.json не найден
```

Решение:

1. Закройте Visual Studio.
2. Удалите папки:

```text
bin
obj
```

3. Откройте терминал в папке проекта.
4. Выполните:

```bash
dotnet restore Sudokugame.csproj
dotnet build Sudokugame.csproj
```

---

### Ошибка NETSDK1005

Если появляется ошибка, что `project.assets.json` не содержит целевого объекта для `net10.0-windows`, значит проект был восстановлен под другую версию .NET.

Решение:

1. Удалите папки:

```text
bin
obj
```

2. Проверьте файл `Sudokugame.csproj`.
3. Убедитесь, что там указан установленный у вас SDK.

Для .NET 10:

```xml
<TargetFramework>net10.0-windows</TargetFramework>
```

Для .NET 8:

```xml
<TargetFramework>net8.0-windows</TargetFramework>
```

4. Выполните:

```bash
dotnet restore Sudokugame.csproj
dotnet build Sudokugame.csproj
```

---

### Игра не открывается после сборки

Команда **Build / Сборка** только компилирует проект.  
Чтобы запустить игру, нужно нажать:

```text
F5
```

или:

```text
Ctrl + F5
```

Также можно использовать команду:

```bash
dotnet run --project Sudokugame.csproj
```

